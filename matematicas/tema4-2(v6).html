Lección: Concepto de Fracción Equivalente

Las fracciones equivalentes son aquellas que se expresan de manera diferente, pero representan exactamente la misma cantidad numéricamente.

Criterios para Comprobar la Equivalencia:

  • Multiplicación Cruzada (Productos Cruzados): Dos fracciones $\frac{a}{b}$ y $\frac{c}{d}$ son equivalentes si y solo si $a \cdot d = b \cdot c$.
  • Ampliación (Amplificación): El valor de una fracción no se altera al multiplicar tanto el numerador como el denominador por un mismo número entero distinto de cero ($k \neq 0$):
    $$\frac{a}{b} = \frac{a \times k}{b \times k}$$
  • Fracciones Mixtas: Para comprobar la equivalencia de fracciones mixtas, es indispensable convertirlas primero a fracciones impropias o simplificar sus partes fraccionarias antes de efectuar los productos cruzados.

Lección: Simplificación de Fracciones

El valor de una fracción no se altera cuando al numerador y denominador se les divide entre el mismo número. A este procedimiento de reducción se le conoce como simplificación de una fracción.

Método Práctico: Factorización de Divisores Comunes

Se colocan el numerador y el denominador alineados. Se traza una línea vertical y se divide sucesivamente entre los factores primos comunes (2, 3, 5, 7...) hasta que ya no haya divisores compartidos. El resultado de la última fila forma la fracción irreducible.
